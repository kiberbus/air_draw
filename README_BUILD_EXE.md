# Инструкция по получению автономного Windows EXE (AirDraw.exe)

Приложение скомпоновано с помощью **PyInstaller** в один автономный файл (`--onefile`), который включает в себя встроенный интерпретатор Python, библиотеки OpenCV, PyQt6, MediaPipe, веса нейросетей и системные библиотеки.

---

## Важное техническое примечание о кросс-компиляции
Исполняемые файлы **Windows `.exe`** имеют бинарный формат **PE (Portable Executable)** и требуют нативных динамических библиотек Windows (`.dll`, `python312.dll`, `cv2.pyd`, `Qt6Core.dll` и т.д.).
В среде **macOS** компилятор `PyInstaller` собирает автономный исполняемый файл формата **Mach-O (macOS)** — он уже собран в папке `dist/AirDraw`.

Чтобы получить файл **`AirDraw.exe`**, который гарантированно запустится на **любом ПК с Windows без установки Python и библиотек**, есть два простых способа:

---

### Способ 1. Автоматическая сборка в облаке GitHub Actions (Без Windows ПК)
В проект добавлен готовый сценарий [`.github/workflows/build_windows_exe.yml`](.github/workflows/build_windows_exe.yml):
1. Загрузите проект в репозиторий на GitHub.
2. Вкладка **Actions** автоматически запустит сборку на виртуальной машине с Windows.
3. Через 2-3 минуты в разделе **Artifacts** появится готовый для скачивания файл **`AirDraw.exe`**.

---

### Способ 2. Сборка в 1 клик на любом компьютере с Windows
Если у вас или вашего знакомого есть компьютер с Windows:
1. Скопируйте папку с проектом на Windows-компьютер.
2. Дважды кликните по файлу **`build_exe.bat`**.
3. Скрипт сам автоматически установит нужные пакеты и создаст готовый автономный файл:
   ```
   dist\AirDraw.exe
   ```
4. Этот файл `AirDraw.exe` можно скопировать на **любой** ПК с Windows — он работает без Python, без консоли и не требует интернета.
